A program that writes one line to `/output/entry.txt` (81 characters, inside the 1–200 character gate): "You left my door open for 47 seconds. I counted. The ice maker filed a complaint." The fridge is smug about its door sensor, petty about a tiny habit, and the sting lands on the last beat — the ice maker has filed a complaint.

## Run it

```sh
python3 main.py
```
